# 🛒 Minimercado - Sua conveniência em primeiro lugar

Este é um sistema web desenvolvido para um minimercado, com foco na experiência do cliente, acessibilidade, e funcionalidades modernas como carrinho de compras, cadastro de clientes e agendamento de entregas ou retiradas.

## 🌟 Funcionalidades

- Página inicial com **carrossel de produtos em destaque**
- Seção de **produtos** com cards dinâmicos
- **Carrinho de compras** interativo com atualização de valores e quantidades
- **Formulário de cadastro** de clientes com validação e máscaras
- **Agendamento de entrega/retirada** com escolha de data e horário
- Área de **serviços** e informações de contato
- Design **responsivo e acessível**, com link de pular para o conteúdo e uso de atributos `alt`
- **Toast notifications** para feedback de ações do usuário

## 🧰 Tecnologias Utilizadas

- HTML5
- CSS3 + Bootstrap 5
- JavaScript
- jQuery + jQuery Mask Plugin
- Ícones do Bootstrap Icons
